Cómo se usa

  1. Avanzar: desliza o usa la rueda para recorrer la sala.
  2. Armario: arrastra a la izquierda para abrirlo y a la derecha para cerrarlo (o botones Abrir/Cerrar, flechas ← →).
  3. Camisetas: pasa el cursor o el dedo para moverlas; toca una para verla en 3D.
  4. Visor: arrastra para girar, rueda para zoom, «Frente ⇄ espalda» y flechas para cambiar de camiseta.
  5. Luz: elige color y modo LED; «Brisa» mueve todas las camisetas; «Diseñar armario» cambia acabado y puertas.
  6. Escanear: pulsa «+ Escanear», haz una foto de una camiseta sobre fondo liso y se cuelga en el armario (hasta 50). Se guarda en este dispositivo.
  7. Amigos: pulsa «Amigos» para agregar gente con su código, ver sus closets y proponer trueques. En una camiseta escaneada, «Poner en trueque» la muestra a tus amigos.
  8. Atajos: B brisa · L luz · H ayuda · Esc cerrar.
